# Workbench fonts

This directory contains the unmodified, self-hosted Source Han Sans CN variable WOFF2 and its SIL Open Font License. It is used by the workbench UI only; video typography remains part of each composition.

Official source: https://github.com/adobe-fonts/source-han-sans/tree/release

Font: `Variable/WOFF2/OTF/Subset/SourceHanSansCN-VF.otf.woff2`.
